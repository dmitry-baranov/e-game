# Архив удалённых политик ботов

Начиная с `bots-v7` в новых сериях доступны только три пользовательские политики: `CAUTIOUS`, `PRICE` и `STOCK`. Служебные `RULES`, `EVAL_RULES` и `MODEL` остаются внутренней частью рекомендательной системы и парной оценки, но не входят в `policyMix`.

Ниже сохранены описания политик из `bots-v6`, удалённых из исполняемого кода. Завершённые исторические серии и аналитические строки с этими именами не изменяются. Незавершённые серии `bots-v6`, содержащие удалённые имена, нельзя возобновлять после обновления.

| Политика | Историческое поведение |
| --- | --- |
| `QUALITY` | Качество 0,85, ассортимент из четырёх видов и реклама интенсивности 2. |
| `EXPLORE` | Воспроизводимо перебирала партию, качество, ассортимент, рекламу и наценку по отдельному seed бота и дню. |
| `PRICE_MEDIAN` | Двигала цену к медиане видимых цен соперников, не более чем на 12% за решение. |
| `PRICE_PREMIUM` | Двигала цену к уровню на 15% выше медианы соперников, шагом не более 15%. |
| `PRICE_CUT_AFTER_ZERO` | Снижала цену на 10% после трёх нулевых дней продаж в недавней истории. |
| `PRICE_RAISE_AFTER_SELLOUT` | Повышала цену на 8%, если минимум два недавних дня завершились распродажей. |
| `PRICE_MARGIN_GUARD` | Считала цену с запасом к себестоимости с учётом ставки налога с продаж. |
| `PRICE_HYSTERESIS` | Сдвигала цену к медиане не более чем на 10% при заметном отличии от рынка и почти неизменной прежней цене. |
| `SALES_SMOOTH` | Корректировала размер партии по средним недавним продажам и прежнему объёму. |
| `STOCK_CLEAR` | При остатке больше половины прежней партии сокращала выпуск на одну мощность и цену на 5%. |
| `STOCKOUT_RECOVER` | При двух недавних распродажах увеличивала партию на одну мощность. |
| `CAPACITY_STEADY` | Назначала партию в две мощности при большом складе, иначе в три. |
| `SHORT_CYCLE` | Назначала партию в одну мощность. |
| `LONG_CYCLE` | При устойчивом спросе и малом складе назначала партию в пять мощностей, иначе в две. |
| `QUALITY_STEP_UP` | Добавляла 0,08 к качеству при достаточном балансе и устойчивых продажах. |
| `QUALITY_BUDGET` | Снижала качество на 0,12 при нехватке денег на ориентировочную стоимость партии. |
| `ASSORTMENT_BROADEN` | Добавляла один вид товара после двух распродаж и при положительном балансе. |
| `ASSORTMENT_FOCUS` | Убирала один вид при нулевых продажах или нехватке денег. |
| `ADS_PULSE` | Чередовала рекламный импульс и паузу при наличии средств. |
| `ADS_STOP_LOSS` | Выключала рекламу после слабого рекламного цикла. |
| `CASH_RESERVE` | Подбирала партию под 70% текущего баланса и отключала рекламу. |
| `DEBT_AVOID` | Подбирала партию под доступный баланс без нового оборотного кредита. |
| `PAYMENT_AWARE` | Резервировала деньги под известные ближайшие платежи. |
| `RIVAL_QUALITY_GAP` | Подтягивала качество к близким по цене конкурентам. |
| `RIVAL_AD_GAP` | Усиливала рекламу в ответ на рекламу конкурента. |
| `PRICE_TWO_LEVELS` | Чередовала две наценки к себестоимости по числу полных циклов. |
| `PRICE_REVENUE_WINDOW` | Сравнивала дневную выручку двух последних полных циклов и двигалась к более выгодной цене. |
| `VOLATILITY_BUFFER` | Снижала выпуск при сильном разбросе недавних продаж. |
| `STOCK_RUNWAY` | Сопоставляла запас с четырьмя днями средних продаж. |
| `ZERO_SALES_PIVOT` | После двух циклов без продаж по очереди улучшала качество или расширяла ассортимент. |
| `CONSERVATIVE_CASH_SCORE` | Сравнивала варианты цены и партии по осторожной оценке остатка денег. |
| `LIMITED_CREDIT_GROWTH` | Увеличивала партию при устойчивых продажах с отдельным лимитом нового кредита. |
| `ADS_DURATION_TEST` | Сравнивала один и два дня рекламы по продажам в день. |
| `QUALITY_PRICE_BUNDLE` | Одновременно меняла качество и цену в зависимости от продаж и склада. |

`RULES` ранее была доступна в `policyMix`; с `bots-v7` она сохранена только как внутренний fallback рекомендательной системы. Полные исходные требования и результаты старого набора остаются в `STRATEGY_AGENTS_STAGE5_TASK.md` и `STRATEGY_AGENTS_STAGE5_IMPLEMENTATION.md`.
