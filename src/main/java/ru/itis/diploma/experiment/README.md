# Как читать эксперимент

Эксперимент проводит обычные игры с автоматическими участниками. Начните с четырёх файлов:

1. [`controller/ExperimentController.java`](controller/ExperimentController.java) принимает настройки серии, даёт предпросмотр и возвращает её текущий статус.
2. [`service/ExperimentManager.java`](service/ExperimentManager.java) сохраняет серию, выдаёт потокам свободные игры, обрабатывает паузу, повтор после ошибки и возобновление после перезапуска. Один поток ведёт одну игру; глобально одновременно работают не более десяти игр.
3. [`service/ExperimentScenarios.java`](service/ExperimentScenarios.java) по seed, номеру попытки и сохранённой версии генератора выбирает рынок, число ботов и параметры игры. Порядок вызовов генератора случайных чисел важен для воспроизводимости старых серий.
4. [`service/ExperimentEngine.java`](service/ExperimentEngine.java) выдаёт попытку под блокировкой серии и проводит **один день в одной транзакции**: фиксирует снимки до всех решений, получает планы от [`bot/BotDecisions.java`](bot/BotDecisions.java), проверяет склад и деньги, записывает результаты через [`service/ExperimentDecisionJournal.java`](service/ExperimentDecisionJournal.java), затем вызывает обычную торговлю. Непринятый план остаётся в журнале, но не создаёт производственного цикла.

Отдельно [`config/ExperimentConfig.java`](config/ExperimentConfig.java) проверяет ввод, [`bot/`](bot/README.md) описывает три политики и создание участников. [`analytics/`](analytics/) читает сохранённые игры: `BotAnalyticsController` формирует страницы, `BotAnalyticsReadRepository` содержит SQL-запросы, `ExperimentReports` считает агрегаты серии. `model/` и `repository/` хранят состояние; их таблицы и историю прежних оценочных серий нельзя смешивать с логикой выбора плана.

Новые серии работают в режиме `COLLECT`. Старые записи `EVALUATE` остаются доступными для анализа, но запуск оценочных игр заблокирован после удаления рекомендательных политик. Поэтому код просмотра старых пар присутствует в отчётах и моделях, не участвуя в новых играх.
