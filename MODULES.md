# Структура приложения

Это **один Spring Boot-проект и один JAR**, который запускается на `:8080` (обычные игры) и `:8081` (эксперименты) с разными настройками и базами. Папки ниже — логические части кода, а не отдельные Maven-модули или серверы.

```text
src/main/java/ru/itis/diploma/
├── game/
│   ├── controller/  # страницы игры, игроков, статистики и советов
│   ├── dto/         # параметры создания игры, производства и снимок стратегии
│   ├── model/       # JPA-сущности игры, аккаунтов, производства и платежей
│   ├── repository/  # хранение игровых сущностей
│   ├── service/     # торговля, покупатель, кредиты и советы
│   │   └── impl/    # реализации игровых сервисов
│   ├── GameSimulation.java
│   └── GameViewExtension.java
├── experiment/
│   ├── analytics/   # статистика серий, игр, ботов и обучение
│   ├── bot/         # фабрика участников и политики ботов, README с маршрутом чтения
│   ├── config/      # проверка параметров серии
│   ├── controller/  # запуск/управление и ссылка со страницы игры
│   ├── model/       # JPA-сущности серий и журнала решений
│   ├── repository/  # хранение серий, попыток и журнала
│   └── service/     # генерация рынков, очередь, проведение игр и журнал
├── security/        # общая авторизация обоих режимов
├── config/          # общая конфигурация Spring
├── validation/      # общие валидаторы
└── exception/       # общие исключения
```

Направление вызовов: `experiment/controller` → `experiment/service` → `experiment/bot` и `game`; аналитика читает результаты эксперимента. **Игра не импортирует эксперимент, а бот не импортирует его хранилище или сервисы.** `ModuleBoundariesTest` проверяет эти границы. Для перехода со страницы игры к экспериментальному отчёту игра содержит лишь интерфейс `GameViewExtension`; реализация лежит в `experiment/controller` и включается только при `experiment.enabled=true`.

Перенос Java-классов изменил пакеты и импорты, но сохранил названия сущностей и таблиц, правила игры, маршруты HTTP и границы транзакций. Внешняя ML-служба остаётся в `ml/`; интерфейс экспериментов доступен только на экспериментальном контуре.

Начать чтение логики можно с [маршрута в README ботов](src/main/java/ru/itis/diploma/experiment/bot/README.md). Результаты реализации интерфейса описаны в [отчёте седьмой итерации](analitics/STRATEGY_AGENTS_STAGE7_IMPLEMENTATION.md).
